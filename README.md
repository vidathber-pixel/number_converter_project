Number System Converter

A Python command-line tool built to convert numbers between Binary, Octal, Decimal, and Hexadecimal number systems.

Features

Multi-Base Support: Converts between Binary (Base 2), Octal (Base 8), Decimal (Base 10), and Hexadecimal (Base 16).

Supports Fractions: Handles decimal points in all bases (e.g., 1010.1 or A.8).

Mathematical Steps: Option to view full step-by-step calculations for each conversion.

Input Validation: Prevents invalid inputs and strips standard prefixes like 0b, 0o, or 0x.

How to Run

Make sure you have Python 3 installed.

Open your terminal or VS Code in the project directory.

Run the script:

python number_converter_project.py


Example

Select Source Base:
  1. Binary (Base 2)
  2. Octal (Base 8)
  3. Decimal (Base 10)
  4. Hexadecimal (Base 16)

Enter choice (1-4): 4
Enter Hexadecimal value: A.8

Results:
  Decimal: 10.5
  Binary: 1010.1
  Octal: 12.4
  Hexadecimal: A.8
