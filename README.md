# 🔢 Number System Converter

A Python-based command-line application that converts numbers between four commonly used number systems: **Binary, Octal, Decimal, and Hexadecimal**.

This project demonstrates fundamental Python programming concepts, including number systems, mathematical operations, input validation, and user interaction.

## ✨ Features

- **Multi-Base Conversion:** Convert between Binary (Base 2), Octal (Base 8), Decimal (Base 10), and Hexadecimal (Base 16).
- **Fractional Number Support:** Handles numbers with fractional parts across all supported number systems.
- **Step-by-Step Calculations:** Displays detailed mathematical steps to help users understand how each conversion works.
- **Input Validation:** Detects invalid inputs and prevents unsupported characters.
- **Prefix Recognition:** Supports standard number system prefixes such as `0b`, `0o`, and `0x`.
- **Interactive CLI:** Provides a simple menu-driven interface for easy navigation.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Interface:** Command-Line Interface (CLI)

## 📋 Supported Number Systems

| Number System | Base | Example |
|---|---:|---|
| Binary | 2 | `1010.1` |
| Octal | 8 | `12.4` |
| Decimal | 10 | `10.5` |
| Hexadecimal | 16 | `A.8` |
